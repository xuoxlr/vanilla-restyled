# Vanilla Restyled

**Vanilla Restyled** aims to improve the vanilla Minecraft experience with a curated selection of mods, resource packs, and shaders, keeping the game familiar without straying too far from the core gameplay.

It includes **e4mc** (an open-source alternative to Essential) so you can easily host worlds and play with your friends.

---

### Reporting Issues
If you run into any bugs, visual glitches, or crashes:
1. Go to the **"Issues"** tab at the top of this repository.
2. Click **New Issue** and select the **Bug Report** template.
3. Fill out the requested details so the issue can be fixed as quickly as possible.
